# 🚀 Neural Vision Engine

### AI-Powered Real-Time Object Detection & Monitoring System

---

## 📌 Overview

Neural Vision Engine is an intelligent computer vision system built using YOLOv8 that performs real-time object detection, tracking, and analytics.
It supports both image uploads and live webcam feeds, making it suitable for applications like traffic monitoring, industrial safety, and smart surveillance.

---

## 🎯 Features

* 🔍 Real-time object detection using YOLOv8
* 🎥 Live webcam detection with tracking
* 🖼️ Image upload detection support
* 📊 Analytics dashboard (object count, trends)
* 🚨 Smart alert system (traffic & safety)
* 💎 Modern glassmorphism UI
* 📥 Download detection results

---

## 🛠️ Tech Stack

* Python
* YOLOv8 (Ultralytics)
* OpenCV
* Streamlit
* NumPy
* Pandas

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/neural-vision-engine.git
cd neural-vision-engine
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```
